# Huawei Band 7 — Heart Rate & Step Count Dataset

**Author:** Michael Kurniawan Soegeng (吳忠賢)
**Collection Period:** March 1–26, 2026 (26 days)
**Subject:** Single user (the author), male, university student
**Device:** Huawei Band 7 (optical PPG heart rate sensor + accelerometer pedometer)

## Overview

This dataset contains minute-level heart rate (BPM) and step count data exported from a Huawei Band 7 wearable device. It was collected for a supervised learning project on cross-modal BPM imputation at NYCU (Spring 2026).

## Data Collection

### Hardware
- **Device:** Huawei Band 7 (model LEA-B19)
- **Sensors:** Optical photoplethysmography (PPG) for heart rate; 3-axis accelerometer for step counting
- **Worn on:** Left wrist, 24/7 (removed only for charging, ~1 hr/day)

### Software
- **Huawei Health** app (Android) — syncs device data to phone
- **Data export:** Huawei Health → Settings → Privacy → Request Data Export → CSV download

### Collection Conditions
- Normal daily activity of a university student (classes, studying, walking, sleeping)
- No controlled exercise protocol — data reflects natural, unstructured daily life
- Heart rate sampling is **device-controlled** (not user-configurable): the watch samples more frequently during detected activity and less during rest/sleep
- Step counting is continuous whenever the device detects arm/body movement
- No external data sources were used; all data originates from the single wearable device

### Sampling Characteristics
- **Heart rate:** Intermittent, event-driven sampling. The device does NOT sample every minute. Coverage is ~32% of the minute-level timeline (11,823 out of 36,930 possible minutes). This creates a **Missing At Random (MAR)** pattern — missingness depends on time-of-day and activity level.
- **Steps:** Interval-based recording. Each record covers a start–end time window (typically 1 minute). Only recorded when steps are detected (no zero-step records).

## Known Limitations

- **Single subject:** Data from one individual; heart rate patterns are person-specific.
- **MAR missingness:** The device samples more during activity, creating systematic gaps during rest/sleep.
- **No ground truth for missing values:** There is no reference device to validate imputed values.
- **Sampling bias:** Observed BPM overrepresents active states, potentially inflating the training distribution mean.
- **Short duration:** 26 days may not capture seasonal or long-term physiological variations.
